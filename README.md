# IoT-Based Home Automation Using Digital Logic

## Overview
This project implements a smart home automation system using ESP32, digital logic circuits, and IoT communication.

## Features
- Motion detection
- Automatic light control
- Wi-Fi/Bluetooth control
- Low-power optimization

## Components Used
- ESP32
- PIR Sensor
- Relay Module
- LEDs
- Logic Gates

## Working
The PIR sensor detects motion and activates the relay to turn ON appliances.

## Power Optimization
- Deep Sleep Mode
- CMOS Logic
- Clock Gating

- Mobile App
